# Contact widget icon options

Created with the built-in image-generation tool, with transparent backgrounds. Blue Reach was selected by the user for the app and tray. Each option has its original PNG and a Windows ICO with 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel images. Conversion only resized and encoded the artwork; it did not change the design.

## reach

A single production-ready Windows desktop app icon for a quick-contacts app. Concept: REACH. A vibrant cobalt-blue rounded-square tile, lightly beveled like a polished modern desktop app icon. Center a bold white speech-bubble outline with one simple human bust silhouette inside; a tiny bold upward-right notch in the bubble suggests reaching out. Keep only one unmistakable central glyph, very large, thick shapes with generous negative space, recognizable even at 16x16 pixels. Premium restrained finish, gentle blue gradient on the tile only, glyph pure white with no tiny details. Front-facing square composition, tile occupies 88% of image, transparent outside the rounded square. No text, no letters, no numbers, no phone keypad, no scene, no presentation sheet, no additional versions. One icon only.
